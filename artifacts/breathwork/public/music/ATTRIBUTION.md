# Bundled classical recordings

The MP3 files in this directory are locally bundled so session playback never
depends on a third-party media URL. They were transcoded for browser
compatibility from the public-domain recordings listed below. The source
recordings were published in the United States no later than 1930, and are in
the U.S. public domain. `energy.mp3` is additionally released under CC0.

| Local file | Work / performance | Source |
| --- | --- | --- |
| `energy.mp3` | Vivaldi — *Spring*, RV 269, I. Allegro; Free Tim | [Internet Archive](https://archive.org/details/parso-19df9720a290ff3dd7678eebf0ac9a400a8406e9) — [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| `focus.mp3` | J. S. Bach — *Passacaglia in C major*; Philadelphia Orchestra / Leopold Stokowski (1929) | [Internet Archive](https://archive.org/details/passacaglia-in-c-major) |
| `adhd.mp3` | Ravel — *Boléro*; Boston Symphony Orchestra / Serge Koussevitzky (1930) | [Internet Archive](https://archive.org/details/bolero_202305) |
| `calm.mp3` | Satie — *Gymnopédie No. 1*; Boston Symphony Orchestra / Serge Koussevitzky (1930) | [Internet Archive](https://archive.org/details/gymnopedie-no-1) |
| `sleep.mp3` | Chopin — *Nocturne, Op. 9 No. 2*; Leopold Godowsky (1916) | [Internet Archive](https://archive.org/details/a-5800-godowsky-chopin-nocturne) |
| `spiritual.mp3` | J. S. Bach — *Air on the G String*; Pablo Casals (1914) | [Internet Archive](https://archive.org/details/1914-air-for-g-string-bach-pablo-casals-col-a-5756) |

The original work titles shown in the goal picker are preserved. When an
original recommended recording is not locally available under a suitable
license, its goal uses the closest matching bundled classical work rather than
making a network request.
